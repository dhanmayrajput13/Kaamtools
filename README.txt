KAAMTOOLS — WEBSITE STARTER
==========================
Included:
- Responsive bilingual (English/Hindi) tools homepage
- Word and character counter
- Text case converter
- Text cleaner
- Percentage calculator
- Age calculator
- About, Privacy Policy, Terms/Disclaimer, Contact pages
- Basic robots.txt and sitemap.xml

IMPORTANT BEFORE PUBLISHING
1. Replace YOUR-DOMAIN.example in index.html, robots.txt and sitemap.xml with your real domain.
2. Replace REPLACE-WITH-YOUR-EMAIL in privacy.html and contact.html.
3. Review every policy page so it accurately reflects your own site and any services you actually use.
4. Test all tools on mobile and desktop.
5. Ad spaces are placeholders only. No ads are active and no AdSense approval is implied.
6. Do not add an AdSense publisher ID or ad code until Google approves your site and provides the code.
7. Add original, helpful explanatory content and make sure the site is genuinely useful before applying.

FREE DEPLOYMENT OPTION: GITHUB PAGES
1. Create/sign in to a GitHub account.
2. Create a public repository, e.g. kaamtools.
3. Upload all files from this folder to the repository root.
4. Open Settings > Pages.
5. Under Build and deployment choose Deploy from a branch, select main and /(root), then Save.
6. Wait for the published URL shown on the Pages settings screen.
7. You can later connect a domain you own through Settings > Pages > Custom domain and follow the DNS instructions.
A GitHub Pages URL is free; buying a custom domain usually costs money. Check the current terms and availability before purchase.

ADSENSE READINESS CHECKLIST
- You own/control the site and can verify it.
- The site has useful original content, clear navigation and a good user experience.
- About, Contact and Privacy Policy pages are accurate and easy to find.
- No broken links, placeholder text, empty sections or misleading content.
- Follow Google Publisher Policies and AdSense program policies.
- Apply in AdSense, add the site, complete the requested ownership verification, and wait for Google's review.
- Approval is not guaranteed. Do not click your own ads, buy fake traffic, or encourage others to click ads.
